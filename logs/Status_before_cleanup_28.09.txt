What is different from results/paper
- Every PDMP run uses --bound-mode single_segment --adapt-rule balanced. One
  tangent-line segment per t_max window, the right end is reused as the next
  window's left end (off with minibatches), t_max starts at the old grid spacing.
- Budgets. Toy G = 200K, UCI small and medium G = 1M, UCI large and images
  K = 1M events. --n-skeleton is only a ceiling on events for the budget runs.
- Every PDMP run saves S = 4000 draws, uniform in time over the trajectory
  after a burn-in of the first 20 % of the time.
- elapsed_sec in v2 is not comparable with v1 (threads, parallel jobs), compare
  gradient_evals instead.

  output dir, never the bare deep_narrow/ dir.

  (--hidden-variant deep_wide --grad-batch-size B), not uci_bnn_grid.py's
  --hidden-variant. The existing results/paper/deep_wide_minibatch/<dataset>/

  "deep_wide_minibatch_piw_0.1" dir so they never touch the existing
  default-PIW files. --stage-size is REQUIRED by this script for any sticky

  makes it safe to target all 5 splits even where some already exist.
